# 物理拷贝

最快的方式物理拷贝。我们知道 mysql 中表都存在一个单独的表空间中，实际就是一个 ibd 文件。当我们通过 create table 创建一个表的时候，
mysql 就会创建一个表空间，并将表空间注册在数据字典中，也就是系统表：SYS_TABLESPACES 中。该表我们时无法查看的，当然在数据库 information_schema
中也有对应的表：innodb_tablespaces;

该表内容如下：
```text
+-------+-------------+-------+------------+-----------+---------------+------------+---------------+-----------+----------------+-----------------+----------------+---------------+------------+-----------+
| SPACE | NAME        | FLAG  | ROW_FORMAT | PAGE_SIZE | ZIP_PAGE_SIZE | SPACE_TYPE | FS_BLOCK_SIZE | FILE_SIZE | ALLOCATED_SIZE | AUTOEXTEND_SIZE | SERVER_VERSION | SPACE_VERSION | ENCRYPTION | STATE     |
+-------+-------------+-------+------------+-----------+---------------+------------+---------------+-----------+----------------+-----------------+----------------+---------------+------------+-----------+
|     2 | test/t      | 16417 | Dynamic    |     16384 |             0 | Single     |          4096 |    131072 |         131072 |               0 | 9.4.0          |             1 | N          | normal    |
|     3 | test/t_copy | 16417 | Dynamic    |     16384 |             0 | Single     |             0 |         0 |              0 |               0 | 9.4.0          |             1 | N          | discarded |
+-------+-------------+-------+------------+-----------+---------------+------------+---------------+-----------+----------------+-----------------+----------------+---------------+------------+-----------+
```

只有在数据目录中的表空间，mysql 才能识别。

了解了上述背景知识后，我们看看如何物理拷贝。假设，现在有个表 t，我们要备份到同一个库中的表 t_copy 下。步骤如下：

- 创建 t_copy 表结构与 t 一致

```sql
    create table t_copy like t;
```
    此时，系统中会注册一个新的表空间，并且会在对应的数据目录下创建一个 t_copy.ibd 文件。

- 我们删除 t_copy 对应的 ibd 文件

```sql
    alter table t_copy discard tablespace;
```

- 我们把 t 表锁住并生成对应的表空间配置信息

```sql
    flush table t for export;
```

会在数据目录下生成一个 t.cfg 文件。注意，这条语句会把 t 锁住，只能读不能写。

- copy t.cfg 和 t.ibd 文件

```shell
    cp t.cfg t_copy.cfg
    cp t.ibd t_copy.ibd
```

这里需要注意这两个 copy 文件的权限，要能让 _mysql 用户识别。

- 解锁 t 表
```sql
    unlock tables;
```

会将 t.cfg 文件删除。

- 导入表空间

虽然我们生成了 t_copy.ibd 文件，但是里面存储的表空间信息与数据字典中的是不一致的，mysql 无法识别。所以
我们还需要执行导入表空间操作。

```sql
    alter table t_copy import tablespace;
```

这条语句会更改 t_copy.ibd 中表空间信息，使其与数据字典中的一致，这样 mysql 就可以识别了。

以上，便完成了一次表的物理 copy.
